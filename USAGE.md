# Usage Notes

This file demonstrates how a pull request branch works with its base branch.

## Steps shown in this demo

1. A feature branch (`feature/usage-notes`) is created from `main`.
2. A file (`USAGE.md`) is committed to the feature branch.
3. A pull request is opened from the feature branch into `main`.
4. A second file (`MAIN-UPDATE.md`) is committed directly to `main`, leaving the pull request behind its base.
5. The pull request branch is updated to bring it in sync with `main`.
